# BenchToBlue UGV_Bot

Autonomous Unmanned Ground Vehicle (UGV) developed using ROS 2 Humble and Gazebo Fortress.

## Repository Structure
- `src/ugv_description`: URDF models, Gazebo Fortress plugins, and spawn launch files.
- `src/`: Directory for all team ROS 2 packages.

## Getting Started

### Prerequisites
- Ubuntu 22.04 LTS
- ROS 2 Humble Desktop
- Gazebo Fortress (`ros-humble-ros-gz`)
